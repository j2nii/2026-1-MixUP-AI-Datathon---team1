# 🔍 QueryTalk
### 비전문가를 위한 Text-to-SQL 기반 실시간 데이터 시각화 에이전트
 
<br>
## 📌 프로젝트 개요
 
**QueryTalk**는 SQL을 몰라도 누구나 자연어(한국어)로 데이터를 조회하고, 즉시 시각화된 인사이트를 얻을 수 있는 Self-service Analytics 에이전트입니다.
 
> 💡 "지난달 웹툰 카테고리별 매출이랑 결제 유저 수 보여줘"  
> → AI가 SQL을 자동 생성하고, 차트와 분석 리포트까지 즉시 제공합니다.
 
<br>
## 🚨 해결하고자 하는 문제
 
현업 비즈니스 환경에서 비전문가와 데이터 분석가 사이에는 고질적인 **데이터 병목 현상**이 존재합니다.
 
```
┌─────────────────────────┐    Ad-hoc 쿼리 요청    ┌─────────────────────────┐
│  현업 부서 (비전문가)      │ ──────────────────> │   데이터 팀 (분석가)      │
│  (기획, 마케팅, 영업)      │ <────────────────── │  (단순 반복 업무 가중)    │
└─────────────────────────┘   지연된 데이터 전달   └─────────────────────────┘
  - SQL 작성 능력 부재           (평균 2~3일 소요)     - 핵심 분석 리소스 고갈
  - 실시간 의사결정 불가                               - 단순 추출기 역할 전락
```
 
| 문제 | 해결 방향 |
|------|-----------|
| 부서 간 소통 장벽 | 자연어 ↔ SQL 자동 번역으로 협업 비용 완전 제거 |
| 데이터 조회 대기 시간 (평균 2~3일) | 실시간 즉시 추출 구조로 전환 |
| SQL 기술 격차에 따른 데이터 접근 불평등 | 데이터 민주화(Data Democratization) 실현 |

## ✨ 주요 기능
 
### End-to-End 에이전트 워크플로우
 
```
[사용자 자연어 질의]
        │
        ▼
┌───────────────────────────────────────────────────────┐
│ 0단계: 동적 스키마 인지 (Dynamic Schema-Awareness)       │
│   - DB 접속 → 최신 테이블 DDL 파싱                       │
│   - 샘플 데이터 기반 '한글 데이터 사전' 자동 생성            │
└───────────────────────────────────────────────────────┘
        │
        ▼
┌───────────────────────────────────────────────────────┐
│ 1단계: 자연어 이해 (NLU) - Solar Pro 3                  │
│   - 의도 파악 / 조건 필터 추출 (기간, 대상 등)              │
└───────────────────────────────────────────────────────┘
        │
        ▼
┌───────────────────────────────────────────────────────┐
│ 2단계: Text-to-SQL 쿼리 자동 생성 - Solar Pro 3         │
│   - DB 스키마 및 데이터 사전 참조                         │
│   - 최적화된 SQL 자동 생성                               │
└───────────────────────────────────────────────────────┘
        │
        ▼
┌───────────────────────────────────────────────────────┐
│ 3단계: 데이터 파이프라인 (Data Pipeline & 검증)           │
│   - 쿼리 실행 및 Raw DataFrame 추출                      │
│   - 에러 핸들링 및 유효성 검사                            │
└───────────────────────────────────────────────────────┘
        │
        ▼
┌───────────────────────────────────────────────────────┐
│ 4단계: 자동 시각화 및 서빙 (Visualization)               │
│   - Plotly 기반 최적 차트 유형 자동 렌더링                 │
│   - 차트 + 자연어 분석 피드백 채팅창 표출                  │
└───────────────────────────────────────────────────────┘
        │
        ▼
[인터랙티브 그래프 + 데이터 테이블 + 간략 분석 리포트]
```

## 🛠 기술 스택
 
| 구분 | 기술 | 역할 |
|------|------|------|
| **AI LLM Engine** | Upstage Solar Pro 3 API | 자연어 파싱, 데이터 사전 매핑, Text-to-SQL, 피드백 텍스트 생성 |
| **Agent Framework** | LangChain / LlamaIndex | SQLAgent 메커니즘으로 LLM ↔ DB 체이닝 및 대화 맥락 유지 |
| **Backend** | Python, SQLAlchemy, Pandas | 안전한 DB 커넥션 관리, Raw Data 가공 및 전처리 |
| **Visualization** | Plotly, Matplotlib | 동적 반응형 그래프/차트 생성 및 렌더링 |
| **Database** | PostgreSQL / MySQL | 비즈니스 트랜잭션 및 매출/유저 로그 적재 |

## 💡 차별점
 
### 기존 서비스 대비 고도화
 
| 비교 항목 | 기존 서비스 (Vanna AI 등) | QueryTalk |
|-----------|--------------------------|-----------|
| SQL 생성 결과 | 단순 반환 | Reflection + SQL Validation으로 Hallucination 최소화 |
| 대시보드 | 고정 템플릿 필터 조작 | 자유 질문으로 새로운 분석 뷰 동적 생성 |
| 스키마 관리 | 수동 갱신 필요 | DB 직접 접속, 한글 메타데이터 사전 자동 생성 |
| 데이터 보안 | - | Read-Only 계정 분리 + 쿼리 실행 전 검증 로직 |
 
### Solar Pro 3 특화 엔지니어링
 
- **한국어 비즈니스 맥락 정량화:** "대박 난 작품" → `ORDER BY revenue DESC LIMIT 5`, "지난달" → `WHERE date >= '2026-04-01'`
- **Few-shot Prompt Engineering:** 산업 데이터 도메인 지식 기반 패턴별 예시 쿼리셋 설계로 환각 최소화
- **대규모 스키마 수용:** 최적화된 컨텍스트 처리로 수많은 테이블 DDL을 압축 수용하여 쿼리 정합성 유지

## 🔮 확장 가능성
 
- **자동 인사이트 요약 고도화:** 수치 데이터 기반으로 Solar Pro 3가 비즈니스 종합 요약 보고서를 자동 작성
